# 申报要求核对与版本控制

用于整稿、合规检查与预算任务。一般写作建议可先给，资格、限项、金额、期限、匿名、字数和附件要求须有对应项目的依据。

## 最小要求表

| 要核对什么 | 记录什么 | 如何影响稿件 |
|---|---|---|
| 机构、年度、类别 | 官方公告标题、链接或用户文件、发布日期 | 决定采用哪份规则 |
| 模板与填写说明 | 版本、下载或核对日期、适用范围 | 确定章节、页数、附件与匿名字段 |
| 资格、限项、期限 | 条款位置及用户已确认事实 | 资料不足时只列待核项，不判定资格 |
| 经费 | 资助方式、可列支项目、额度与计算口径 | 按任务、单价、数量和依据编制 |
| 单位流程 | 内部截止日、审核与盖章要求 | 区分单位时间与资助方时间 |

官方公告、指南、系统最新模板及补充通知一起核对。不同文件冲突时检查适用类别、发布日期和更正说明；仍不清楚则保留冲突并指向主管部门核实，不自造优先级。

## 写作时怎样使用

把已核实要求映射到实际章节。每项研究任务对应目标、材料、方法、判断标准和失败后的替代路径。预期成果保持计划语气，研究基础只写已有记录可支持的工作。

没有现行指南时，先交研究论证草稿及少量待核项。预算不沿用旧书的金额或间接费比例。未知数值留空或标待补，不用示例数字填满表格。

国家社科年度项目单独核对对应公告、附件及活页要求，不把自科的结构迁入社科。[2026 年国家社科年度项目公告](https://www.nopss.gov.cn/n1/2026/0506/c431027-40714613.html)

## 停止与交付

用户要求的章节已完成、事实来源可核对、适用规则已记录即可交付。未核项单列，不用反复改写掩盖信息缺口。用户要求最终提交版本时，未核资格或关键格式必须明确告知，不能用“已合规”收尾。
