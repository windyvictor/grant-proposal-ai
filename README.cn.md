# grant-proposal-ai

[English](README.md) | 中文 · [Research Skillbox 总导航](https://github.com/windyvictor/research-skillbox)

> **课题 / 基金申请书**写作指南 —— 覆盖申报书全部组成部分 + 40 个结构化提示词模板。

## 一句话定位

把 263 页的申报书写作专著，压缩成一份「查得到、用得上」的写作参考与提示词手册。

## 你会得到什么

- 动笔前先建立“科学问题—目标—研究内容—方法—验证证据”的对应关系
- 立项依据、研究内容、技术路线、创新点、可行性、摘要和预算说明等具体稿件
- 对已有研究基础与未来计划的严格区分，不把计划写成成果
- 依据资助机构、年度、项目类别和正式模板形成的合规待核清单

工作路径是：**确认当年申报要求 → 建立研究论证图 → 起草指定部分 → 检查内部对应关系 → 列出仍需核实的格式与额度**。语言可以后改，研究逻辑不能靠模板补出来。

## 何时触发

请求辅助撰写课题申报书、基金申请书（国家自科 / 社科基金、省部级课题），
或需要申报书某个部分的写法（立项依据、研究内容、关键科学问题、技术路线、创新点、
可行性、研究基础、预期成果、经费预算、摘要）。
触发词：「课题申报」「基金申请」「申请书写作」「立项依据」「技术路线」「申报书提示词」。

## 内容结构

```text
grant-proposal-ai/
├── SKILL.md
└── references/
    ├── research-plan-design.md    # 问题、方法、数据、验证与可行性
    └── proposal-writing-guide.md   # 各部分写作要领 + 40 个提示词模板 + 分步工作流
```

三种使用层次：

1. **要某一部分怎么写** → 定位对应章节的写作要领
2. **要提示词** → 取用 40 个模板（含 SRGCD、TMAQ 等结构化提示法，`【】` 为变量占位符）
3. **要整体流程** → 用文件中的分步工作流章节
